# 盈利能力演進概要

## 目的

目前系統主要定位是台股即時看盤、資料整合與視覺化儀表板；已具備即時報價、分鐘 K、爆量偵測、法人籌碼、新聞與 AI 顧問評分等資料基礎，但尚未形成可驗證、可執行、可控風險的交易系統。

若目標是提高「可盈利」機率，首要工作不是直接調整 UI 或單一評分權重，而是補齊交易訊號、回測、風控、交易紀錄與模擬交易閉環。

## 現況判斷

- `src/data/signals.py` 目前是未使用 stub，且註解明確提醒不可直接接到 UI 或生產訊號。
- `src/data/advisor.py` 的 AI advisor 是觀察型評分與建議，不是經回測驗證的買賣系統。
- `src/processor/volume_spike_detector.py` 只偵測成交量相對基準放大，尚未結合趨勢、價位、籌碼、大盤與流動性脈絡。
- 專案目前沒有明確的 backtest、position、portfolio、order executor、trade journal 或 performance 模組。
- Shioaji 目前主要用於行情與資料串流，尚未建立下單與部位控管閉環。

## 需要新增或重構的核心模組

### 1. 交易訊號層

新增正式的 `SignalEngine`，取代目前未使用的訊號 stub。

建議輸出欄位：

- `action`: `entry` / `exit` / `hold` / `avoid`
- `side`: `long` / `short` / `none`
- `confidence`: 0 到 1
- `score`: 綜合分數
- `reasons`: 觸發理由
- `invalidations`: 訊號失效條件
- `risk`: 建議停損、停利、部位風險

第一版策略可優先從「爆量 + 趨勢 + 籌碼」開始，因為專案已經有相關資料來源。

### 2. 回測模組

新增 `src/backtest/`，用既有日線與分鐘線資料驗證策略。

必要功能：

- 套用同一套 `SignalEngine` 產生歷史訊號。
- 模擬進場、出場、停損、停利。
- 計入台股交易成本：手續費、證交稅、滑價。
- 處理漲跌停、流動性不足、開盤跳空等成交限制。
- 支援單股、 watchlist、全市場候選池回測。

### 3. 風控與部位管理

新增 `src/trading/risk.py` 或等價模組。

必備規則：

- 單筆最大風險，例如總資金 0.5% 到 1%。
- 最大持股檔數。
- 單股最大資金占比。
- 每日最大虧損限制。
- 固定停損、移動停利、時間停損。
- 連續虧損後降低部位或暫停交易。

### 4. 交易日誌與績效統計

新增交易日誌資料層，讓每個訊號與每筆交易可以被追蹤。

需要記錄：

- 訊號產生時間。
- 當時報價、K 線、爆量、籌碼、新聞、AI advisor 快照。
- 是否進場。
- 進場價、出場價、持有時間。
- 出場原因。
- 已實現損益與成本。

績效指標至少包含：

- 勝率。
- 平均盈虧比。
- 期望值。
- 最大回撤。
- 交易次數。
- 資金曲線。
- Sharpe 或類似風險調整後報酬指標。

### 5. Paper Trading

在任何實單下單前，先新增 paper trading。

目標：

- 使用即時資料跑同一套策略。
- 只記錄模擬成交，不送出真實委託。
- 比對即時表現與歷史回測是否落差過大。
- 收集滑價、延遲、成交不可得等實務問題。

### 6. 實單下單層

最後再新增 `OrderExecutor`。

實單下單前置條件：

- 回測結果有正期望值。
- Paper trading 至少跑過一段完整市場情境。
- 已有部位控管、每日虧損限制、異常停機機制。
- 所有下單行為都有日誌與可追溯依據。

## 建議優先順序

1. 新增 `SignalEngine`，先把訊號從「觀察敘述」改成可機器判斷的交易決策。
2. 新增 `Backtester`，先驗證策略扣除成本後是否有正期望值。
3. 新增 `RiskManager`，把每筆交易風險與總體曝險限制納入策略。
4. 新增 `TradeJournal` 與績效統計。
5. 在 UI 顯示策略績效、近期訊號與交易理由。
6. 新增 paper trading。
7. 最後才接實單下單。

## 第一版可行策略方向

第一版不建議做全自動交易，建議先做可回測訊號：

- 多方候選：
  - 價格站上 MA20 或 MA60。
  - 當日或分鐘級出現有效爆量。
  - 爆量 K 線收紅或突破近期高點。
  - 外資、投信或融資結構至少一項同向支持。
  - 大盤與類股不是明顯弱勢。

- 避免進場：
  - 爆量但收黑或上影線過長。
  - 跌破關鍵均線。
  - 流動性不足。
  - 新聞或事件面出現重大利空。
  - 當日已觸發最大虧損或連續虧損冷卻。

- 出場：
  - 固定停損。
  - 跌破短期均線。
  - 爆量長黑。
  - 達成停利後移動停利。
  - 持有超過策略設定時間但未延續。

## 成功判準

在進入自動下單前，至少要能回答：

- 策略過去 3、6、12 個月扣除成本後是否正報酬。
- 最大回撤是否可接受。
- 是否只靠少數極端交易撐起績效。
- 不同市場情境下是否仍能控制虧損。
- 即時 paper trading 是否接近回測假設。

只有當上述問題能用資料回答，才適合討論實單下單。
